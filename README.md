# 🐼 Pandas Series – Hands-on Tasks  

This repository is a structured guide to mastering **Pandas Series**, one of the core data structures in the Pandas library.  

It features **6 practical tasks**, starting from beginner-level Series creation to essential indexing, slicing, and operations.  
Perfect for learners who want to build a strong foundation in **Pandas Series manipulation & data handling**.

# ✅ What I Practiced  

- 📋 **Series from Python lists** – Default integer indexing, element access, aggregation (`.sum()`)  
- 🏷️ **Custom Indexing** – Label-based access, updating values using string labels  
- 🔢 **Series from NumPy arrays** – Integration and element-wise operations (`.mul()`)  
- 🅰️ **Custom Alphabetical Indexing** – Label-based access with NumPy arrays  
- 🍎 **Series from Dictionaries** – Key-value mapping and dynamic addition  
- ➕ **Mathematical Operations** – Addition, subtraction, multiplication between Series  
- ✂️ Accessing elements using **loc & iloc**  
- 📊 Using aggregation methods like **`.sum()`**
